# Endpoint Security

## Controls

### Windows Defender

- Real-time protection enabled
- Antivirus enabled
- Security monitoring enabled

### Windows Firewall

Enabled on:

- Domain
- Private
- Public

### Sysmon

Provides:

- Process creation telemetry
- Network connection telemetry
- Process hashes
- Parent/child process relationships

### PowerShell Logging

Enabled for security monitoring.

### Wazuh

Collects endpoint security events.
