# Enterprise Infrastructure & Security Lab

## Overview

This repository documents an enterprise-style infrastructure and
security lab designed to demonstrate practical IT infrastructure,
network security, endpoint security, monitoring, incident response,
and backup/recovery capabilities.

## Environment

The environment includes:

- Windows Server
- Active Directory
- Windows endpoint
- FortiGate firewall
- Network segmentation
- Endpoint security
- Wazuh SIEM
- Incident response procedures
- Backup and recovery

## Objectives

The lab demonstrates the ability to:

- Deploy enterprise infrastructure
- Manage Windows systems
- Implement Active Directory
- Configure network security
- Segment networks
- Harden endpoints
- Monitor security events
- Respond to incidents
- Perform backup and recovery
- Produce enterprise IT documentation
