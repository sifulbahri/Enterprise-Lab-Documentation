# Incident Response

## Response Lifecycle

1. Preparation
2. Detection
3. Analysis
4. Containment
5. Eradication
6. Recovery
7. Lessons Learned

## Incident Severity

| Severity | Example |
|---|---|
| Low | Single suspicious event |
| Medium | Suspected endpoint compromise |
| High | Multiple compromised systems |
| Critical | Domain compromise / ransomware |
