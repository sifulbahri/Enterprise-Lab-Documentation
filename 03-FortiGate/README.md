# FortiGate Enterprise Firewall

## Device

FW01

## Responsibilities

- Internet gateway
- Firewall policy enforcement
- NAT
- VLAN routing
- Security logging
- Network segmentation

## Security Policy

Traffic should follow least privilege.

Default principle:

DENY unless explicitly allowed.

## Management

Management access should be restricted to trusted administrative
networks.

## Logging

Security-relevant traffic and administrative events are logged.
